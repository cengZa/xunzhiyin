# Controller Route Check

此检查对应 `docs/02_design/api_design.md` 的主接口路径与 HTTP 方法。

## 脚本
- `scripts/check-controller-routes.ps1`

## 当前覆盖
- 用户创建与查询
- 用户标签绑定与查询
- 用户画像构建与查询
- 推荐列表与详情
- 单条推荐解释
- 反馈提交与反馈记录查询

## 规则
- 文档要求的主路由必须存在。
- 当前允许控制器中存在额外辅助接口，不视为失败。
- 管理与测试接口在设计文档中标为“可选”，当前不纳入检查。

## 当前限制
- 只按注解文本检查，不解析 Spring 路由组合。
- 不检查请求参数、响应体字段和校验注解是否完全匹配文档。
