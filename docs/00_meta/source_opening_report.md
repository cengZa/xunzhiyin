## 开题报告核心结论

### 1. 项目定位
- 本项目是工程实践型本科毕设，不是科研型算法论文。
- 研究对象是校园场景下的用户-用户匹配推荐，而不是商品或内容推荐。
- 推荐链路应保持为：画像 -> 召回 -> 排序 -> 重排 -> 解释 -> 反馈。
- 可选使用 LLM 做“证据约束解释生成”的文本润色，但不参与排序决策。

### 2. 目标场景
- 兴趣社交匹配：篮球、编程、读书、摄影等兴趣连接。
- 学术协作匹配：课程项目、机器学习研究、竞赛组队等方向连接。
- 校园活动匹配：社团招新、志愿活动、年级交流等组织活动连接。

### 3. 三个核心功能模块
1. 基于改进 TF-IDF 的用户兴趣画像构建
2. 候选用户召回与相似度排序优化
3. 内生可解释推荐生成与反馈更新机制

### 4. 开题报告中的量化目标
- 画像阶段：
  - 特色标签平均权重提升不低于 30%
  - 基于兴趣向量的相似度排序实验中，`Precision@10 >= 0.7`
  - 用户画像构建时间不超过 1 秒
- 召回与排序阶段：
  - 候选召回覆盖率不低于 90%
  - Top-10 结果中，人工标注或问卷验证的匹配度满意比例不低于 70%
  - 系统响应时间控制在 2 秒以内
  - 校园场景约束满足率达到 95% 以上
- 解释与反馈阶段：
  - 推荐解释与核心贡献标签的一致率不低于 95%
  - 推荐理由理解度问卷平均不低于 4/5
  - 反馈后画像更新时间不超过 1 秒
  - 多轮反馈后 `Precision@10` 提升不低于 10%

### 5. 导师意见中对后续工作的硬要求
- 进一步明确实验数据来源
- 进一步明确评价指标定义
- 强化“研究目标 -> 验证方法 -> 结果评价”的对应关系
