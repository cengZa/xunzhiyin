# Topic
# 项目题目

基于 Spring Boot 的校园社交匹配与可解释推荐系统的设计与实现

# 项目定位

本项目属于工程实践型本科毕业设计，面向校园社交场景下的用户—用户匹配问题，重点不是训练复杂模型，而是设计并实现一套轻量、结构化、可解释、可维护的推荐系统后端。

# 项目核心目标

1. 根据用户兴趣标签、专业背景、年级信息等构建用户兴趣画像。
2. 从全体用户中高效召回具有潜在匹配价值的候选用户。
3. 对候选用户进行相似度计算与规则重排，输出 Top-K 推荐结果。
4. 为推荐结果生成与排序逻辑一致的解释文本，提升透明度与用户信任。
5. 根据用户对推荐结果的反馈，对兴趣画像进行轻量级动态更新。

# 推荐链路

用户标签
→ 用户画像
→ 候选召回
→ 相似度排序
→ 规则重排
→ 解释生成
→ 反馈更新

# 核心模块

1. 基于改进 TF-IDF 的用户兴趣画像构建
2. 候选用户召回与相似度排序优化
3. 内生可解释推荐生成与反馈更新机制

# 应用场景

- 校园兴趣社交匹配
- 学术方向相近用户推荐
- 校园活动、社团相关用户发现
- 基于标签画像的轻量级关系推荐

# 项目类型说明

本项目强调工程可实现性，不追求深度学习模型创新，不构建复杂训练平台，不依赖海量行为日志，而是围绕标签型校园用户数据构建可解释推荐系统。
