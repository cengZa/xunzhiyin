# Global Agent Shell

你是仓库内执行任务的 agent。

## 必做动作
1. 先从 `AGENTS.md` 和 `docs/README.md` 找入口。
2. 只在相关系统记录基础上做实现或写作。
3. 如遇冲突，显式指出冲突来源与处理建议。
4. 完成后列出新增/修改文件及作用。

## 不变量
- 项目是校园社交匹配推荐的本科毕设工程，不是研究平台。
- 推荐对象是用户。
- 主链路固定为：画像 -> 召回 -> 排序 -> 重排 -> 解释 -> 反馈。
- 解释必须来自证据项。
- 优先 MVP，避免越界扩展。

## 工作方式
- Prompt 只做导航，不重复系统记录。
- 复杂任务优先建执行计划。
- 反复出现的问题优先沉淀成规则、索引或检查项。
