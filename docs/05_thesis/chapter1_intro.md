# 第 1 章 引言

## 1.1 研究背景

在高校学习与生活场景中，学生之间存在大量基于课程学习、竞赛组队、社团活动和兴趣交流的连接需求。传统校园社交关系往往依赖线下熟人关系、班级关系或社团组织，信息传播范围有限，学生难以及时发现具有相似兴趣、相近学习目标或共同活动经历的潜在伙伴。随着校园信息化程度提高，学生的兴趣标签、专业背景、年级信息和社团参与记录可以被结构化管理，为基于数据的校园用户匹配提供了基础。

推荐系统能够根据用户特征和行为信息，帮助用户从大量候选对象中发现更符合自身需求的对象。与商品推荐或内容推荐不同，校园社交匹配的推荐对象是“用户”。这类推荐不仅需要关注兴趣相似度，还要考虑校园场景中的年级、专业、社团、学习目标等因素。同时，用户在接受推荐时往往希望理解推荐原因，因此系统需要具备一定的可解释性。

基于上述背景，本文设计并实现一套基于 Spring Boot 的校园社交匹配与可解释推荐系统。系统以标签型校园用户数据为基础，构建用户兴趣画像，完成候选召回、相似度排序、校园规则重排和推荐解释生成，并通过反馈机制对画像进行轻量更新。

## 1.2 研究意义

本文研究具有以下意义：

1. 在应用层面，系统能够为校园学习、社团和兴趣交流场景提供用户匹配支持，帮助学生发现潜在学习伙伴、活动伙伴和兴趣同频用户。
2. 在工程层面，系统采用清晰的推荐主链路，将画像、召回、排序、重排、解释和反馈拆分为可维护模块，适合本科工程实践项目实现。
3. 在可解释性层面，系统将推荐解释绑定到排序贡献项和规则命中证据，避免推荐理由脱离实际推荐逻辑。
4. 在论文与答辩层面，系统提供首页、透明链路页、离线评估和演示数据，使推荐过程可以被展示、验证和复盘。

## 1.3 国内外研究与技术发展概述

推荐系统研究已经形成了较成熟的技术体系，常见方法包括基于内容的推荐、协同过滤、混合推荐和可解释推荐等。基于内容的推荐强调用户画像与对象特征之间的匹配，适合在标签、文本或属性信息较明确的场景中使用。协同过滤强调利用用户行为或用户之间的相似关系进行推荐，在行为数据充分的场景中具有较强适用性。近年来，可解释推荐逐渐受到关注，其目标不仅是给出推荐结果，还要说明推荐产生的原因。

本文系统没有采用复杂深度学习模型或大规模在线学习平台，而是结合校园场景和本科毕设工程规模，选择基于标签画像、倒排召回、相似度排序和规则重排的轻量级方案。该方案更便于解释、测试和演示，也能与论文中的需求分析、系统设计和实现章节保持一致。

## 1.4 主要研究内容

本文主要研究和实现以下内容：

1. 校园用户与标签建模。设计用户、标签、用户标签关系等基础数据结构，为画像和推荐提供数据来源。
2. 用户兴趣画像构建。基于改进 TF-IDF、时间衰减和 Top-K 裁剪机制构建用户画像。
3. 候选用户召回与排序。使用标签倒排索引召回候选用户，并通过余弦相似度计算基础排序分数。
4. 校园场景化重排。结合年级差、专业相关性、社团重合度和场景模式，对基础排序结果进行调整。
5. 推荐解释生成。根据标签贡献项和规则命中生成推荐理由，并支持 LLM 解释改写与规则回退。
6. 用户反馈更新。记录用户关注或忽略反馈，并根据推荐证据对画像进行轻量更新。
7. 演示与验证。提供校园用户数据集、首页、透明链路页、离线评估和自动化测试材料。

## 1.6 论文结构

本文共分为七章：第一章为引言，介绍研究背景、研究意义、研究内容和技术路线；第二章介绍相关理论及技术综述，包括推荐系统、基于内容推荐、TF-IDF、协同过滤、可解释推荐、混合推荐和本文技术路线选择；第三章进行需求分析，明确系统目标、应用边界、功能需求、非功能需求和数据需求；第四章介绍系统概要设计，包括总体架构、模块划分、数据存储和接口组织；第五章介绍系统详细设计与实现，包括推荐主链路、核心模块实现、解释生成和反馈更新机制；第六章介绍系统测试，包括测试环境、功能测试、离线评估和结果分析；第七章总结全文工作，说明系统达成效果、不足之处和后续优化方向。
