# 中文摘要

校园学习、社团活动和兴趣交流中存在较多用户匹配需求。传统基于标签重叠的匹配方式容易受到热门标签影响，难以区分不同校园场景，也缺少清晰的推荐依据。针对上述问题，本文设计并实现了一套基于 Spring Boot 的校园社交匹配与可解释推荐系统，用于在学习搭子、社团搭子和兴趣同频等场景下为用户推荐潜在连接对象。

系统采用 Java 21 与 Spring Boot 构建，使用 MySQL 保存用户、标签、画像、推荐结果、解释和反馈等结构化数据，使用 Redis 支撑标签倒排召回和画像缓存。系统推荐链路包括用户画像构建、候选召回、相似度排序、校园规则重排、推荐解释生成和反馈更新。画像构建阶段在 TF-IDF 基础上加入时间衰减和 Top-K 裁剪；排序阶段使用余弦相似度计算用户兴趣相似性；重排阶段结合年级差、专业相关性、社团重合度、场景模式和可信连接分调整结果。推荐解释由标签贡献、规则命中和可信连接原因生成，大语言模型仅作为解释文本润色能力，并保留规则解释回退。

测试阶段通过系统测试数据集、自动化测试、治理检查和离线评估对系统进行验证。结果表明，系统能够完成从用户标签到 Top-K 推荐结果的完整链路，并能够展示推荐分数、匹配标签、规则命中、可信连接原因和解释文本。系统还提供透明链路展示、双视图对比和评估导出能力，可支撑系统分析与结果复核。

本文工作表明，在校园社交匹配场景下，通过结构化推荐链路和证据绑定解释机制，可以在保持工程实现轻量的同时提高推荐过程的可解释性和可验证性。

关键词：校园推荐；用户画像；TF-IDF；可解释推荐；规则重排；反馈更新
