## 3. 标题迁移规则

Markdown 源稿使用 `第 X 章` 便于本地阅读。迁入 Word 时按模板改为：

| Markdown 标题 | Word 标题 |
| --- | --- |
| `# 第 1 章 引言` | `1 引言` |
| `## 1.1 研究背景` | `1.1 研究背景` |
| `# 第 7 章 总结与展望` | `7 总结与展望` |
