# 第 7 章 总结与展望

本章对校园社交匹配与可解释推荐系统的设计、实现和测试工作进行总结，并说明当前系统的不足与后续优化方向。本文的目标是完成一个面向本科工程实践的推荐系统，使其具备可运行、可解释、可演示和可验证的基本能力，而不是构建大规模线上推荐平台。

## 7.1 工作总结

本文围绕校园学习、社团和兴趣交流场景，设计并实现了一套基于 Spring Boot 的校园社交匹配与可解释推荐系统。系统以校园用户标签为基础，通过用户画像、候选召回、相似度排序、校园规则重排、推荐解释和用户反馈构成完整推荐链路。

本文主要完成了以下工作：

1. 完成系统需求分析，明确推荐对象为校园用户，系统边界集中在用户匹配推荐、解释生成、反馈更新和演示评估。
2. 完成系统概要设计，设计了接口层、服务层、策略层、数据访问层和基础设施层组成的后端结构。
3. 完成核心数据设计，建立用户、标签、用户标签关系、用户画像、推荐结果、推荐解释和用户反馈等数据模型。
4. 实现用户画像构建机制，在 TF-IDF 基础上结合时间衰减和 Top-K 裁剪生成兴趣画像。
5. 实现候选召回与排序机制，通过标签倒排索引召回候选用户，并使用余弦相似度计算基础兴趣分。
6. 实现场景化重排机制，结合年级差、专业相关性、社团重合度、可信连接分和轻量探索机制调整推荐结果。
7. 实现推荐解释机制，使解释文本能够回溯到标签贡献、规则命中和可信连接原因，并支持 LLM 改写失败时回退到规则解释。
8. 实现用户反馈闭环，记录关注或忽略反馈，并根据推荐证据对画像进行轻量更新。
9. 建立测试和演示材料，通过自动化测试、治理检查、透明链路页面、双视图对比和离线代理评估支撑论文分析与答辩展示。

## 7.2 系统达成效果

从功能实现看，系统已经覆盖用户管理、标签管理、画像生成、候选召回、排序重排、推荐解释、反馈采集、推荐记录持久化和演示评估等主要功能。推荐结果能够返回匹配标签、规则命中、可信连接原因、推荐分数和解释文本，满足校园匹配推荐系统的基本使用要求。

从可解释性看，系统没有将推荐解释作为独立文本生成任务处理，而是先在排序和重排阶段保留贡献项与规则命中，再由解释模块生成推荐理由。LLM 仅用于解释文本润色，不参与召回、排序、重排、可信连接分或反馈更新，因此推荐解释与推荐计算之间能够保持一致。

从测试验证看，系统已经通过自动化测试和治理检查。最近一次 Maven 测试结果为 23 个测试运行、0 个失败、0 个错误、1 个按环境条件跳过；治理检查覆盖文档引用、后端骨架、模块边界、服务签名、控制器路由、API 合约和 Java 工具链。离线评估使用模拟校园用户数据和代理相关性规则，能够验证推荐链路可运行、结果可解释和策略可对比。

## 7.3 项目特点

本文系统的特点主要体现在以下方面：

1. 面向校园场景。系统围绕学习搭子、社团搭子和兴趣同频等校园需求组织推荐逻辑，而不是照搬商品推荐或内容推荐模式。
2. 推荐链路完整。系统覆盖画像、召回、排序、重排、解释和反馈，不停留在简单标签重叠匹配。
3. 解释证据可追溯。推荐解释绑定共同标签、标签贡献、规则命中和可信连接原因，降低解释与排序依据不一致的风险。
4. 工程结构清晰。后端模块按 controller、service、strategy、mapper、domain 和 infra 分层组织，便于测试和维护。
5. 验证边界明确。论文区分自动化测试、代理评估和真实用户实验，不将模拟数据结论写成真实线上效果。

## 7.4 不足之处

受数据来源和项目周期限制，系统仍存在以下不足：

1. 当前测试和评估主要基于模拟校园用户数据，尚未接入真实校园用户数据。
2. 离线评估中的相关性判断采用代理规则，缺少正式人工标注和问卷验证。
3. 开题报告中的部分量化目标，例如真实用户满意度、多轮反馈后 Precision@10 提升比例和响应时间统计，目前缺少完整实验材料。
4. 可信连接分和轻量探索机制仍属于规则化设计，尚未经过大规模参数调优。
5. 系统当前面向小规模校园数据和毕业设计演示场景，未针对高并发访问和大规模数据处理进行专门优化。

## 7.5 后续展望

后续工作可以从以下方面展开：

1. 引入小规模人工标注或问卷数据，对推荐满意度和解释理解度进行更正式的验证。
2. 扩充模拟数据或接入脱敏真实数据，检验推荐链路在更复杂用户关系下的稳定性。
3. 对场景权重、可信连接分和轻量探索阈值进行更多参数实验，形成更完整的对比分析。
4. 增加画像构建、推荐接口和反馈更新的响应时间统计，补充性能测试材料。
5. 将治理检查、Maven 测试和本地联调整合为更完整的一键验证或 CI 流程。
6. 在保持解释证据可控的前提下，继续优化 LLM 解释改写效果，使推荐理由更自然、更易理解。

## 7.6 本章小结

本文完成了一个面向校园社交匹配场景的可解释推荐系统。系统通过结构化推荐链路和证据绑定解释机制，实现了从用户画像到推荐结果再到反馈更新的闭环。虽然当前评估仍以模拟数据和代理规则为主，但系统已经具备较完整的工程实现、测试验证和答辩展示能力，为后续真实数据验证和进一步优化奠定了基础。
