## 3. 不可过度表述项

论文中不能写成既成事实的内容：

- 已完成所有社交产品能力。
- 已完成大规模高并发场景调优。
- 推荐效果已达到工业级推荐平台水平。
- 所有开题报告量化目标均已正式达成。
- LLM 参与召回、排序、重排、可信连接分或反馈更新。
- 轻量探索机制已经过大规模实验调优。
- 当前 Precision@K 是绝对化推荐满意度指标。

建议写法：

- 当前实验基于系统测试数据集和相关性判定规则。
- 当前结果用于验证推荐链路可运行、可解释、可对比。
- 多轮反馈收益和大规模性能测试属于后续工作。

## 7. 定稿前检查顺序

1. 按本页检查过度表述。
2. 检查 `references.md` 编号与正文引用是否一致。
3. 根据 `figures_and_tables_plan.md`、`chapter3_diagram_drafts.md`、`chapter4_diagram_drafts.md` 和 `chapter5_diagram_drafts.md` 完成必要架构图、流程图、ER 图、类图、时序图和核心表格。
4. 根据 `word_assembly_readiness.md` 和 `thesis_outline.md` 把 Markdown 正文内容迁入学校 Word 模板。
5. 按模板处理封面、目录、图题、表题、参考文献和页眉页脚。
6. 最后运行 `scripts/run-governance-checks.ps1`，确认文档链接未损坏。
