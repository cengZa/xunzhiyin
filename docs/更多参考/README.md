# 更多参考

本目录保存论文结构、格式、答辩和工程型写作参考原件。该目录是参考输入库，不直接作为论文正文迁入。

## 当前材料

- `第5-2章-毕设正文及答辩.pdf`: 工程型论文正文写作、图表、参考文献和答辩要求的主要依据。
- `本科论文-工程型样例-刘.docx`: 工程型本科论文样例，重点参考目录结构、章节写法、图表组织和 Word 格式。
- `第5-1章-毕设摘要及目录.pdf`: 摘要和目录写作参考。
- `22301095-林乘吉-开题报告.docx`、`22301095-林乘吉-开题报告.pdf`: 本项目开题材料。
- `3-1.png`、`5-1.png`、`5-2.png`、`ER图.png`: 样例图表或可视化参考。

## 使用规则

- 原始参考材料只归档，不删除、不改写。
- 结构决策写入 `../05_thesis/thesis_outline.md`。
- 论文正文不直接引用本目录文件名，正式参考文献统一维护在 `../05_thesis/references.md` 和 `../参考文献/`。
