# Project Scope
# 项目范围说明

## 一、项目目标

本项目围绕校园社交场景下的用户—用户匹配问题，设计并实现一套结构化、可解释、轻量级的推荐系统。系统通过用户标签构建兴趣画像，并基于倒排索引、向量相似度计算和校园规则重排输出推荐结果，同时生成与排序依据一致的推荐解释，并根据用户反馈对画像进行轻量更新。

## 二、项目要解决的问题

1. 热门标签过强导致用户画像区分度不足
2. 从全体用户中召回候选对象的效率问题
3. 推荐结果缺乏解释，用户不易理解推荐原因
4. 用户兴趣随时间变化，静态画像不够灵活
5. 结构化推荐链路不清晰时，工程实现与论文表达容易脱节

## 三、项目包含内容

### 1. 用户基础信息管理
- 用户基本资料录入
- 年级、专业、社团等基础字段维护

### 2. 标签管理
- 标签分类定义
- 用户标签选择与维护
- 标签与用户关系管理

### 3. 兴趣画像构建
- 基于改进 TF-IDF 计算标签权重
- 引入时间衰减机制
- 生成用户 Top-K 兴趣向量

### 4. 推荐主链路
- 基于倒排索引的候选召回
- 基于余弦相似度的排序
- 基于校园规则的重排

### 5. 推荐解释
- 提取排序贡献项
- 生成结构化推荐理由
- 提供解释查询接口

### 6. 反馈更新
- 采集用户对推荐对象的关注或忽略反馈
- 轻量更新相关标签权重
- 支持下一轮推荐使用新画像

### 7. 基础测试与结果展示
- 功能测试
- 推荐示例输出
- 解释示例输出
- 结果合理性分析

## 四、项目不包含内容

1. 复杂社交即时聊天模块
2. 社区发帖、评论、内容审核等完整社区能力
3. 深度学习推荐模型训练
4. 大规模在线实验平台
5. 复杂分布式推荐系统架构
6. 多端完整前端产品化实现

## 五、项目成功标准

1. 能够完成从用户标签到推荐结果的完整主链路
2. 能输出 Top-K 推荐结果
3. 每条推荐结果都有可追溯的解释依据
4. 系统支持简单反馈并对画像进行轻量更新
5. 论文内容与系统实现保持一致
