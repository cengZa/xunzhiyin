# Harness Engineering Note

来源：OpenAI, "Harness engineering: leveraging Codex in an agent-first world", 2026-02-11。

## 本项目吸收的做法
- 使用短 `AGENTS.md` 作为目录，而不是大而全手册。
- 把 `docs/` 作为记录系统。
- 将计划视为一等工件并纳入版本控制。
- 采用渐进披露，让 agent 从小入口逐步读取上下文。
- 用质量、可靠性、技术债文档补足长期治理。

## 当前未落实的做法
- 文档结构 lint
- doc-gardening 自动维护
- 更强的可观测性与自动验证回路
